# k6_frac_n10_2x2

K6 N10 fracturable-LUT tileable fabric, 2x2 core, logic only (I/O and CLB)

Logic only: it has no memory and no multiplier, so it has no techlib.

Grid 2x2 (core), LUT size 6, channel width 20 for the reference design.
Made from the task `basic_tests/generate_fabric`. The paths inside `arch/openfpga_arch.xml` are relative to this
directory. See `docs/spec_device_package.md`.
