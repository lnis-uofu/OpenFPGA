# nlohmann/json

JSON for Modern C++, version 3.10.5 (https://github.com/nlohmann/json), the
single header `include/nlohmann/json.hpp`, unchanged. MIT license
(`LICENSE.MIT`). The shell reads JSON with it, e.g., the data that a plugin
keeps in a session (its attachments).

The file is not formatted by `make format-cpp`, which leaves `libs/EXTERNAL`
out.
